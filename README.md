# Twin Studio

数字孪生三维场景编辑器和 Viewer SDK。

## 运行

需要 Node 20.16+ 和 pnpm 10.20。

```bash
pnpm install
```

```bash
pnpm dev
```

自带模拟后端，数据存在 `apps/editor/.mock-data/`。真实后端接入、对象存储上传时序及请求示例见[前后端接口文档](API.md)。

## 编辑器怎么用

资源库和编辑器底部共用同一份模型列表。在任一入口点「上传模型」，选择一个或多个 GLB，填写标题后确认。编辑器卡片在同一行显示标题和文件大小，可直接拖入视口。拖动两侧栏内缘或底部资源栏上缘可调整大小，资源卡片向下滚动浏览。选中模型，在「属性 → 整体材质」可改玻璃、金属、发光或透视效果，修改只作用于当前实例。新场景提供一个可编辑、可删除的「示例设备」。修改标题和删除模型在资源库卡片的「更多」菜单里操作。

1. **摆场景：** 从底部资源栏把模型拖进视口，左栏是场景树，右栏改属性。视口左侧切换选择、移动、旋转、缩放，右上角切换透视、顶、前、右视图。选中物体后按 R 或点左侧「等比缩放」，拖动轴端手柄即可放大或缩小。右侧「属性 → 变换 → 缩放」默认勾选「锁定比例」，修改任一轴会同比调整另外两轴，取消勾选可单独输入各轴的缩放值。
   左侧工具栏的「绘制能流线」可在地面或模型表面逐点取线。至少取两点，双击终点或按回车完成，Backspace 撤回上一点，Esc 取消。完成后随场景保存。
2. **存镜头：** 左栏「镜头」里点「添加当前镜头」，点缩略图卡片切换过去。点镜头下的「设为封面」可立即替换项目卡片封面，也可以从项目卡片的「⋯ → 更改封面」上传图片。之后保存场景或删除来源镜头都会保留已选封面。
3. **配数据：** 不选中对象时，右栏是数据接口，一条条添加：HTTP（默认只请求一次，可以打开定时请求）、WebSocket 推送、手填的静态数据。选中对象后在「数据」页签绑定设备。「管理设备类型」可以添加、编辑或删除当前场景的类型，也可以配置编号前缀和默认变量。单个绑定、批量绑定和标签组共用这份列表；已绑定的设备保留自己的类型和变量。
4. **加信息面板：** 场景树上方点「标签」新建标签组，选中它，右栏配置模板（标题、宽度、字段），再点「添加子元素」，在场景里左键点击放置面板。面板放在标签组下面，改模板时一起变，也可以单独覆盖标题和隐藏字段。面板和物体一样近大远小，并且始终面向镜头。
5. **看效果：** 点「预览」，点击对象可以选中；在对象的「交互」里添加「镜头聚焦」才会移动镜头。
6. **给大屏用：** 保存后场景就是后端的一份 JSON，大屏取到 JSON，交给 Viewer SDK，SDK 自动去重资源 ID、批量获取下载地址并加载模型。

在物体的「交互」标签中选择触发和响应，保存后可在预览和外部大屏执行。外部大屏也能列出场景镜头并按 ID 切换。[Viewer 镜头接入示例](packages/viewer/README.md#大屏镜头选择器)

快捷键：Q / W / E / R 选择、移动、旋转、缩放；H 显隐；End 放到地面；0 / 7 / 1 / 3 透视、顶、前、右视图；Ctrl+S 保存；Ctrl+Z / Y 撤销重做；Ctrl+C / V 复制粘贴；Ctrl+D 创建副本；Ctrl+G 组合；Delete 删除；P 预览；Esc 退出预览或结束放置。

## 园区案例与特效

在「3D场景 → 生成案例」中选择「零碳智慧园区（卡通版）」或「储能园区（精致版）」。每次创建独立的项目，模型复用资源库里的相同文件。卡通案例包含储能、光伏、风电和办公区的能流展示；精致案例包含储能柜阵列、升压站和光伏车棚。示例使用静态设备读数，可以替换成实际数据源。

选中物体，进入「特效」标签添加常驻特效，或为绑定设备设置按变量触发的告警规则。保存后编辑器预览和 Viewer 0.13.0 均会渲染相同效果。案例模型来源见[署名说明](apps/editor/public/campuses/CREDITS.md)。
